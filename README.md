Real-Time BitStock Tracker

A real-time BitCoin + Indian Stock Market live price tracker built using React, Node.js, WebSockets, and Docker — deployed on Vercel (frontend) and Render (backend).

This project streams live price updates every second without page reloads, using WebSockets for instant communication.
